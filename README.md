# Komentář k zákonu č. 155/1998 Sb., o komunikačních systémech neslyšících a hluchoslepých osob

Otevřený komentář k zákonu o komunikačních systémech neslyšících a hluchoslepých osob — § po §: doslovné znění, výklad, kazuistika, protiargumenty a praktický závěr; český znakový jazyk, komunikační systémy vycházející z češtiny, právo na tlumočnické služby a kursy pro rodiče.
